title: "Which Random Forest Tuning Parameters Matter?"
author: "Rahaf Alabdullah (rahafaa2)"
---

A random forest has many tuning parameters: the number of trees, the number of candidate predictors at each split (mtry), the terminal node size, and the sample size used to grow each tree. For complicated data, for example many predictors where only a few are informative, which parameters should we focus on tuning, and which can we safely leave at their defaults? How does each important parameter affect the bias–variance tradeoff?
